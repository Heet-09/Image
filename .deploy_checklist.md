# Pre-Deployment Checklist

## Before Deploying to New Server

### Files to Transfer ✅
- [ ] `cbir_app/` directory (entire folder)
- [ ] `cbir_project/` directory (entire folder)
- [ ] `nginx/` directory
- [ ] `Dockerfile`
- [ ] `docker-compose.prod.yml`
- [ ] `docker-compose.yml`
- [ ] `requirements.txt`
- [ ] `manage.py`
- [ ] Static files (if any)

### Optional Files
- [ ] `data/` directory (if you have existing data)
- [ ] `media/` directory (if you have uploaded images)
- [ ] `.env` file (if using environment variables)

### Files to EXCLUDE ❌
- [ ] `__pycache__/` folders
- [ ] `*.pyc` files
- [ ] `inv_venv/` or any local virtual environments
- [ ] `.git/` folder (unless using Git to deploy)
- [ ] `node_modules/` (if any)

---

## Quick Transfer Commands

### Using Git (Recommended)
```bash
# On new server
git clone <your-repo-url>
cd Image
```

### Using SCP
```bash
# From your local machine
scp -r cbir_app/ cbir_project/ nginx/ docker-compose*.yml Dockerfile requirements.txt manage.py user@server:/path/to/Image/
```

### Using Rsync
```bash
rsync -avz --exclude='__pycache__' --exclude='*.pyc' --exclude='inv_venv' ./ user@server:/path/to/Image/
```

## First-Time Setup on New Server

1. **Transfer files** ✅
2. **SSH into server** ✅
3. **Install Docker** (if not installed):
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
4. **Install Docker Compose** (if not installed):
   ```bash
   pip install docker-compose
   # or
   sudo curl -L "https://github.com/docker/compose/releases/download/v2.0.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
   sudo chmod +x /usr/local/bin/docker-compose
   ```
5. **Navigate to project**:
   ```bash
   cd /path/to/Image
   ```
6. **Edit passwords** in `docker-compose.prod.yml`
7. **Run deployment**:
   ```bash
   docker-compose -f docker-compose.prod.yml up -d --build
   ```
8. **Run migrations**:
   ```bash
   docker-compose -f docker-compose.prod.yml exec web python manage.py migrate
   ```

## Verify Deployment

Check these URLs work:
- [ ] http://your-server-ip/ (Homepage loads)
- [ ] http://your-server-ip/cbir/search/ (Search page loads)
- [ ] http://your-server-ip/cbir/upload/ (Upload page loads)

Check containers are running:
```bash
docker-compose -f docker-compose.prod.yml ps
```
Should show 3 containers: db, web, nginx

## Important Settings to Update

Edit `cbir_project/settings.py`:
- [ ] `ALLOWED_HOSTS` - Add your server IP/domain
- [ ] `SECRET_KEY` - Generate new one for production
- [ ] `DEBUG = False` - For production

Edit `docker-compose.prod.yml`:
- [ ] MySQL passwords
- [ ] Port mappings (if needed)

## After Deployment

Monitor logs:
```bash
docker-compose -f docker-compose.prod.yml logs -f
```

Test functionality:
- [ ] Upload an image
- [ ] Search for an image
- [ ] Check results appear correctly
